# 改道规则表（v0.1）

> 触发后输出"改道建议卡"，列触发条件、建议动作、需家长确认。不自动改道。

| 触发条件 | 判定标准 | 建议动作 | 需确认 |
|---|---|---|---|
| 连续2周抵触 | 连续5天打卡状态≤2，或明确说"不想做" | 降门槛：口述变三句话，听读变10分钟 | 是 |
| 连续4周无可见变化 | 周回测该项连续4周"无可见变化" | 检查承接枝是否找错、材料是否太难、门槛是否太高 | 是 |
| 连续6周无变化 | 同上持续6周 | 停该动作，换承接枝，复诊五问 | 是 |
| 孩子突然着迷某主题 | 家长观察或打卡记录 | 最近承接优先，顺主题加材料 | 否（建议即可） |
| 规则未覆盖 | 组合不在表内 | 回归承接律推断，标注"理论推断" | 是 |
