# 回测字段表（v0.1）

## 观察清单（第0周，家长填）

- 主动提问：频率、主题类型
- 复述能力：能否说出开头/经过/结果
- 阅读偏好：故事/科普/历史/漫画
- 英语：听词指图？字母发音？CVC拼读？
- 迁移：新词换场景用过吗
- 抵触点：哪个动作一碰就躲

## 日打卡（每天三字段）

- 保底动作完成？是/否
- 孩子状态 1—5
- 一个新发现/抵触点

**日回测只调门槛，不调方向。**

## 周回测（四字段）

- 承接枝变化：有/无/不确定
- 表达变化：差/中/好
- 持续抵触动作：有/无（哪个）
- 材料是否接不住：是/否

**周回测调材料、调时长、调承接枝，不轻易换路径类型。**

## 月复诊（五问）

1. 根：新增生活体验/阅读材料了吗？
2. 干：能更清楚复述一件事或一篇文章吗？
3. 承接枝/形成层：新词/句式能用在另一个场景吗？
4. 叶：迁移任务能过吗？
5. 砍留：哪些贴叶子该淡化或砍？哪些抵触该改道？

**月复测才做"继续/暂停/换承接枝"的策略决定。**
